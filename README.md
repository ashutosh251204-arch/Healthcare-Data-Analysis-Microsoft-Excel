# Healthcare Data Analysis Dashboard | Microsoft Excel
Healthcare Data Analysis Dashboard using Microsoft Excel, Pivot Tables, and Data Visualization to analyze patient trends and healthcare metrics.
## Project Overview
Developed a Healthcare Data Analysis Dashboard using Microsoft Excel to analyze patient records and identify trends in hospital admissions, medical conditions, billing, and patient demographics.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Data Analysis
- Data Visualization
- Excel Charts
- Dashboard Development

## Dashboard Features

1. **Yearly Patient Trend:** Analyzes patient trends over the years.
2. **Medical Condition Analysis:** Compares patient counts across different medical conditions.
3. **Year-wise Condition Analysis:** Visualizes medical-condition trends across years.
4. **Test Result Analysis:** Compares test results with medical conditions.
5. **Admission Type Analysis:** Examines admission types across medical conditions.
6. **Gender Analysis:** Compares patient distribution by gender and medical condition.
7. **Age Group Analysis:** Explores age-group distribution across medical conditions.

## Key Performance Indicators
